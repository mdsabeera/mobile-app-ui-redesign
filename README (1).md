# 📱 Mobile App UI Redesign

A UI/UX redesign project focused on improving the usability and visual appeal of an existing mobile application, created by **Mohammed Sabeera Begum**.

---

## 🎯 Project Goal

To redesign the user interface of an existing mobile app with a focus on:
- Better usability and user experience
- Modern and clean visual design
- Smooth interactions and transitions

---

## 🔍 Design Process

1. **User Research** – Identified pain points in the existing app
2. **Personas & User Flows** – Created user personas and mapped out key user journeys
3. **Wireframing** – Low-fidelity wireframes for layout planning
4. **High-Fidelity Design** – Polished screens designed in Figma
5. **Prototype** – Clickable interactive prototype with smooth transitions

---

## 🛠️ Tools Used

- **Figma** – Wireframing, UI Design & Prototyping
- **Adobe XD** – Additional design exploration

---

## ✨ Key Improvements

- Simplified navigation structure
- Improved visual hierarchy and typography
- Consistent color scheme and design system
- Accessible design following WCAG guidelines
- Interactive components with smooth transitions
